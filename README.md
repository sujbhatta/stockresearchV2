# Stock Research Dashboard

A live stock analysis tool that fetches Indian stock data, calculates technical indicators, and generates AI-powered investment reports using Google Gemini.

## Features

- **Real-time Stock Data**: Fetches NIFTY 50 stock data from Yahoo Finance
- **Technical Indicators**: Calculates MA20, MA50, MA200, and RSI(14)
- **Interactive Charts**: Beautiful Chart.js visualizations with price and RSI charts
- **AI-Powered Reports**: Investment analysis reports generated by Google Gemini 2.0 Flash
- **Smart Caching**: Filesystem-based caching with 24-hour TTL to reduce API calls
- **Responsive Design**: Clean Bootstrap 5 interface that works on all devices

## Tech Stack

- **Backend**: Flask
- **Frontend**: Bootstrap 5 + Chart.js + Vanilla JavaScript
- **Data Source**: yfinance (Yahoo Finance) with CSV fallback
- **AI**: Google Gemini 2.0 Flash API
- **Caching**: CSV files (1-day TTL)

## Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd stockresearchV2
```

2. Create a virtual environment (recommended):
```bash
python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

3. Install dependencies:
```bash
pip install -r requirements.txt
```

4. Set up environment variables:
```bash
cp .env.example .env
```

5. Edit `.env` and add your Google Gemini API key:
```
GOOGLE_API_KEY=your_actual_api_key_here
```

Get your API key from: https://makersuite.google.com/app/apikey

## Usage

1. Start the Flask application:
```bash
python app.py
```

2. Open your browser and navigate to:
```
http://localhost:5000
```

3. Select a stock from the dropdown menu

4. View the price chart, technical indicators, and key metrics

5. Click "Generate AI Report" for an investment analysis

## API Endpoints

### GET /
Renders the main dashboard HTML page.

### GET /api/stock/<symbol>
Returns stock data with technical indicators.

**Response:**
```json
{
  "symbol": "RELIANCE",
  "price": 2450.50,
  "high52w": 2856.00,
  "low52w": 2220.30,
  "pe_ratio": 28.5,
  "market_cap": 1650000000000,
  "ma20": 2445.60,
  "ma50": 2520.30,
  "ma200": 2600.80,
  "rsi": 55.4,
  "ohlcv_data": [...]
}
```

### GET /api/report/<symbol>
Generates AI-powered investment report using Google Gemini.

**Response:**
```json
{
  "report": "Investment report text..."
}
```

## How It Works

1. **Data Fetching**:
   - Checks if cached data exists and is less than 24 hours old
   - If not, fetches fresh data from Yahoo Finance (yfinance)
   - Saves to `cache/<symbol>.NS.csv`
   - Falls back to cache if API is unavailable

2. **Technical Analysis**:
   - Calculates Moving Averages (20, 50, 200 days)
   - Calculates RSI (14-day Relative Strength Index)
   - Determines 3-month price trend

3. **AI Report Generation**:
   - Sends stock data to Google Gemini 2.0 Flash
   - Receives detailed investment analysis
   - Displays in a clean modal popup

## Customization

### Add More Stocks
Edit the `NIFTY_50_STOCKS` list in `app.py` to add more stocks.

### Change Cache Duration
Modify `CACHE_TTL_HOURS` in `app.py` (default: 24 hours).

### Customize AI Prompt
Edit the prompt template in the `generate_report()` function in `app.py`.

## Troubleshooting

### "GOOGLE_API_KEY not configured" error
Make sure you've created a `.env` file with your Google Gemini API key.

### "No data returned for {symbol}" error
- Check your internet connection
- Verify the stock symbol is correct (should be from NIFTY 50)
- Try clearing the cache folder and refetching

### Charts not displaying
- Check browser console for JavaScript errors
- Ensure Chart.js CDN is loading properly
- Verify the stock data is being returned correctly
